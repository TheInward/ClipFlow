# 2026-10-29 安全与稳定性检查

## 已修复

- 写入接口（包含登录、退出、资产删除）校验 Origin 与 Sec-Fetch-Site，拒绝跨站操作。保留无浏览器头的服务端调用兼容性；身份认证仍然必需。
- 仅信任本机反向代理提供的转发头，采用 X-Forwarded-For 最后一个 IP，防止伪造首段绕过限流。部署约定：Node 端口仅监听回环，Nginx 必须追加真实客户端地址；多层代理需重新配置可信链。
- 登录、注册、验证码和会话接口统一限流，429 返回 Retry-After。
- 令牌桶在正常流量中也清理过期项，并限制条目总数，避免不断更换请求键导致内存增长。
- 添加 CSP（外部脚本仅同源、禁止插件与网页嵌套）、nosniff、来源策略和权限策略。移除通配 CORS；媒体允许远程 HTTP/HTTPS，以兼容现有上游结果。
- JSON 请求仅接受对象；拒绝 null、数组和原始类型。
- 模型参数仅允许 duration、resolution、seed；种子校验整数范围。参考 URL 只能由服务器根据已验证归属的素材产生。
- 数据库临时文件权限为 0600；退出保存使用独立临时文件和原子替换，避免直接截断主文件。
- 被暂停的白名单/管理员账号也不能绕过暂停限制。

## 界面调整

保留灰白基调，提升辅助文字对比度，降低标题尺寸和卡片阴影。四个工具等宽排列，复刻预览在中屏切换纵向布局，手机优先显示输入区。补充键盘焦点和减少动画适配。

## 验证范围与边界

43 项自动测试通过，包括 HTTP 权限隔离、任务互斥、资产归属、批量任务、取消/退款、跨站请求、伪造 IP 限流、参数注入、Hypit 桥接。另使用独立本地测试库检查登录及页面切换；没有提交付费模型任务。

这不是第三方渗透测试或安全认证。以下仍需上线运营配置：

- HTTPS：公网使用明文 HTTP 时，密码、会话和素材传输仍存在窃听风险。需要域名和受信任证书，然后配置跳转与 Secure Cookie；不能仅靠应用安全头替代 TLS。
- 备份恢复：JSON 数据库只支持单进程写入；多实例/扩容前迁移到事务数据库，定期离机备份并演练恢复。
- 存储治理：完善按账号容量配额、媒体/私有 Hypit 项目缓存的保留策略和磁盘告警。
- 任务不确定性：上游已受理但网络超时时不能保证自动找回回执。当前保留异常提示且不自动重复提交收费请求；仍需要服务商幂等键/对账能力。
- Hypit 模型尚未接通，本次不把桥接测试等同于真实视频生成成功。
