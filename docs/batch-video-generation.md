# 批量视频生成

创作窗口支持 1、2、3、5、10 条；默认 1 条。多条是一个批次，当前账号的批次未结束时不能删除或提交另一批。

## 差异如何产生

每条共用原提示词和参考素材，同时增加独立的场景细节、光线和运镜方向，使用互不重复的随机种子。原提示词、主体身份、产品外观和标识保持优先；首尾帧模式保持起止画面的约束。

这是要求模型产生变化，不是保证任意两条输出都存在明显的视觉差异。服务商返回相同地址、或保存后的文件 SHA-256 相同时，会标记为重复，不计入批次有效结果；资产里也会标注。内容相同但重新编码后字节不同的情况，目前没有额外的视觉相似度检测。

## 提交、恢复与费用

- 一次只向服务商提交一条，确认前一条结束后才提交下一条。
- 服务器后台继续运行，关闭网页不会停止当前批次。
- 提交前先持久化“正在提交”，取得服务商任务号后再次持久化。重启时恢复已有任务号；若记录显示提交中但没有任务号，停止自动提交并提示人工核对，不冒险重复计费。
- 普通云端生成失败可以继续下一个版本；提交失败或响应不明确时停止剩余提交。失败、跳过、重复均单独显示。
- 每条按服务商规则分别计费；重复或失败结果不自动付费重试。网站自身的视频积分计费规则仍待接入。
- 单次提交响应超时后，前端先查询当前任务恢复，不直接再次提交。

## 查看结果

创作页保留一个预览窗口，可点击不同版本切换。显示批次进度、各条状态和有效结果数；每条完成视频独立进入当前账号资产。批次删除只清理任务展示，资产仍可独立下载和删除。

## 验证

32 项测试通过，覆盖并发查询、串行提交、重启恢复、没有任务号时停止、提交失败停止、重复地址及文件哈希判定、条数校验、账号隔离，以及 10 组方向和种子不同。服务商在测试中使用模拟接口，未新增真实付费生成。

视频复刻仍等待能接收视频参考的 H3 接口，本次不会启用其实际生成能力。
