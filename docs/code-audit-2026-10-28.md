| 后台参考图上传的异常被转成成功的 Promise | 生成流程无法正确感知上传失败 | 保留失败结果并允许后续重试 |

| 普通用户可以触发全站过期清理接口 | 普通账号可执行系统维护操作 | 限制为管理员 |
| 对比滑块在 0% 时把数值当成空值 | 方向键从最左端错误跳到中间 | 正确保留 0%，增加端点键盘回归验证 |
| 视频预览重建时未显式暂停旧播放器，对比视频加载失败无兜底 | 可能残留播放声音或黑屏 | 重建前暂停；加载失败展示说明与下载入口 |
| 登录提交没有实际设置 `loginPending` | 回车等操作可能重复发送登录请求 | 请求期间加锁并在结束后释放 |
| README 仍说明裸文件链接可匿名访问 | 与实际权限规则不一致 | 更新签名链接与账号隔离说明 |

## 尚未完成或需要明确的规则

1. **视频生成积分计费：高优先级。** 工具处理已有扣费和失败退款，视频生成没有接入网站积分校验、扣费、退款；界面的“预计积分”没有计算值。零积分账号仍可请求生成，消耗配置的服务商账户余额。需要确定三种工作流、分辨率、时长的积分价格，以及提交超时后如何核对任务，才能实现可靠计费，不能直接套用未确认的价格。
2. **旧版图片创作台：未接入。** `pageStudio`、`studioSend` 保留旧的图片/视频生成草稿，发送只弹出“尚未开通”。当前顶部“创作”进入的是已经实现的 AutoDL 创作页，旧页面没有顶部入口。后续应删除旧页面及其专用样式、事件，或在决定支持图片生成后独立实现。
3. **运维与数据规模。** 主存储仍为单个 JSON 文件，资产失败重试依赖后续同步请求；没有数据库事务、按容量配额或资产保存重试队列。适合目前单实例部署，用户量增加前应单独改造。
